# Decisions

- 2026-11-06 — The TypeScript policy adapter now mirrors `CreditEngine` autonomy semantics: its default per-draw cap is 2% of borrowing power and its 12-hour window allows three draws. A World step-up is required only when the contract-synchronised `needsStepUp` flag is set; locked-liquidity consent remains separately required for an excess unwind. This resolves the earlier adapter's unsourced fixed debt threshold and keeps the on-chain contract as the authority.
- 2026-11-06 — The first live treasury adapter targets USDY's Ethereum Oracle Wrapper, not a hard-coded underlying oracle call. It follows the wrapper target at the observed block, resolves its verified `ScheduledOracleSwitch` when present (with an optional reviewed implementation pin), derives `accrualPerSecondWad` as USD per USDY per second from Ondo's continuously compounded rate, and pins the last active price/rate update transaction. A public redemption pause closes the modeled gate; individual KYC status is never inferred from public chain state.
- 2026-11-06 — Indexer writes select `RPC_BASE_SEPOLIA` when configured with `CHAIN_ID=84532`; Ethereum mainnet remains a read-only source through `RPC_ETH_MAINNET`. Testnet deployment and oracle posting do not require production-chain transactions.
- 2026-11-06 — The Base Sepolia hook deployment uses Uniswap's official v4 PoolManager and PositionManager addresses from the published deployment table; these are recorded in `.env.example` and `docs/testnet.md` instead of asking the user to supply them.
